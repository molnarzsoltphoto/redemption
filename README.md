# Redemption

Böngészős noir nyomozós játék egy Budapest-szerű városban. Főhős: Mátrai Dénes, a gyilkossági osztály alkoholista főhadnagya.

**Játék:** https://molnarzsoltphoto.github.io/redemption/

## Ügyek
1. **A Révész** – november
2. **Fehér hidak** – december

A személyes döntések (lányod, apád, Nóra, a stáb lojalitása) átkerülnek a következő ügybe. A mentés a böngészőben tárolódik.

## Forrás
A `src/` mappában: `engine.js` (motor), `case1.js`, `case2.js` (ügyek), `shell.html` (váz és stílus). A `build.py` ezekből állítja össze az `index.html`-t.
